# Traveloop 🌍✈️

Traveloop is a modern travel planning web application built using HTML, CSS, and JavaScript.
The project helps users organize trips, manage itineraries, calculate budgets, maintain packing checklists, and save travel notes through a responsive and user-friendly interface.

This project was developed for the Odoo Hackathon at Parul University and focuses on creating a clean, modular, and interactive travel planning experience inspired by modern travel platforms.

---

# 🚀 Features

* User Login & Signup UI
* Responsive Landing Page
* Dashboard Overview
* Create & Manage Trips
* Itinerary Planning
* Budget Calculator
* Packing Checklist
* Notes / Journal System
* Shared Trip Preview
* Dark / Light Theme
* Modern Glassmorphism Design
* LocalStorage Data Persistence

---

# 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API
* Font Awesome Icons

# ▶️ How to Run

1. Download or clone the repository
2. Open the project folder in VS Code
3. Install Live Server extension
4. Right-click `index.html`
5. Click `Open with Live Server`
